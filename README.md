# Гараж на районе

Играбельная сборка драг-рейсинг-прототипа для «Рынка пацана».

**Играть:** https://sudarikovandrey.github.io/garage-na-rayone/

Портретный экран, одна кнопка: старт и переключение передач в зелёной зоне.
Кампания на 225 заездов, 13 машин, тюнинг, ящики, пять стадий гаража.
Прогресс хранится в браузере.

Ивент «Сезон асфальта» и дуэли PvP здесь недоступны: им нужен серверный
Worker с базой, который живёт в закрытой публикации на Sites.

Снимок коммита `cd0c709` («[claude] Логотип на экране позывного — к самому номеру»). Исходники — в локальном репозитории
проекта, эта ветка пересобирается скриптом целиком.
